# 🎞 一卷胶片 — 一镜到底网页作品集

以「一卷胶片」为开场概念：角色沿胶片往前走，一格一格点亮他的作品，
最后胶片收束成一道光爆开，进入作品世界。
深绿 + 黑白线稿 + 奶油白配色，取材自桌面 `人物` 文件夹里的角色参考图。

## 打开方式

直接用浏览器打开 `index.html` 即可（无需联网，无外部依赖）。

## 文件结构

```
作品集/
├─ index.html          # 页面结构（胶片开场 / 关于 / 能力 / 作品 / 联系）
├─ css/style.css       # 样式：胶片、放映光束、颗粒噪点、响应式
├─ js/main.js          # 交互：胶片推进、逐格点亮、灯箱、滚动、星空
├─ assets/
│  └─ refs/            # 你的角色参考原图（来自桌面「人物」）
└─ README.md
```

## 开场玩法（一卷胶片）

- 页面加载完成后（素材预载完约 1 秒）**自动开始循环放映**，无需任何点击；
- 胶片逐格推进：先是 3·2·1 片头倒数，然后依次点亮 7 格作品，底部字幕显示当前作品名与 FRAME 计数；
- 每放完一轮会**自动回卷并重新开始，无限循环**；
- 按钮在 **「⏸ 暂停放映 / ▶ 继续放映」** 之间切换（点胶片画面同样有效）；
- 滚出开场区域后循环暂停，回到顶部会自动接着放；顶部 **「↺ 重播开场」** 可从第一格重新开始；
- 左上角色头像随滚动沿进度线移动。

## 调节循环节奏

在 `js/main.js` 里搜索这几个常量即可：
- `MOVE`：每格移动时长（默认 340ms）
- `HOLD`：每格停顿（默认 430ms）
- `LOOP_HOLD`：一轮结束后的停留（默认 900ms）
- `REWIND`：回卷时长（默认 700ms）

## 怎么替换成你自己的内容

1. **角色图**：覆盖 `assets/refs/` 里的同名图片即可；
   - 出镜角色（胶片中央的“演员”）用 `character-green.png`
   - 圆形头像用 `character-half.png`
2. **姓名 / 文案**：搜索 `index.html` 里的 `童帅` 全文替换；邮箱与社交链接在「联系」区块。
3. **作品格**：打开 `js/main.js` 顶部的 `WORKS` 数组，复制一行改 `src / title / tag / desc`；
   胶片会按数组顺序逐格点亮。
4. **调节放映时长**：在 `js/main.js` 里搜索 `duration = reduceMotion ? 0 : 9500`，改这个毫秒数即可。
