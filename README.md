# 🚪 推开我的世界 — 一镜到底网页作品集

一个以「虚拟角色推开大门、走进自己的世界」为概念的动效风格网页作品集。
深绿 + 黑白线稿 + 奶油白配色，取材自桌面 `人物` 文件夹里的角色参考图。

## 打开方式

直接用浏览器打开 `index.html` 即可（无需联网，无外部依赖）。

## 文件结构

```
作品集/
├─ index.html          # 页面结构（大门 / 关于 / 能力 / 作品 / 联系）
├─ css/style.css       # 全部样式与大门开启动效
├─ js/main.js          # 交互逻辑（开门、滚动、灯箱、星空）
├─ assets/
│  └─ refs/            # 你的角色参考原图（已从桌面「人物」复制）
└─ README.md
```

## 怎么替换成你自己的内容

1. **角色图**：直接覆盖 `assets/refs/` 里的同名图片即可；
   - 大门内主视觉建议 16:9 横图（当前为 `character-green.png`）
   - 圆形头像使用方形图（当前为 `character-half.png`）
2. **姓名 / 文案**：搜索 `index.html` 中的 `童帅` 全文替换；邮箱与社交链接在「联系」区块。
3. **作品**：打开 `js/main.js` 顶部的 `WORKS` 数组，复制一行并改 `src / title / tag / desc`；
   图片放进 `assets/`（或 `assets/works/`）后把路径填进 `src`。
4. **加视频项目**：目前作品区以图片为主，`WORKS` 数组里加 `src` 为视频封面图、标题注明“视频”即可，后续可自行把卡片链接改成 `<video>`。

## 开场玩法

- 页面加载时先预载角色素材，按钮可用后点击 **「🚪 推开大门」**（或直接点大门）；
- 大门向两侧旋转打开 → 门内主视觉浮现 → 页面自动平滑滚入「关于我」，
  之后向下滚动即“一镜到底”走进作品的各个分区；
- 左上角色头像会随滚动沿左侧进度线移动，显示当前所在分区；
- 顶部导航的 **「↺ 重播开场」** 可回到大门重新推开。
